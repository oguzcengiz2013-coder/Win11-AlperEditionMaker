# Win11-AlperEditionMaker

Win11-AlperEditionMaker is a tool for creating a customized Windows 11 installation ISO from your own Windows 11 installation media.

It automates common ISO customization tasks and makes it easier to build a personalized Windows 11 installer without manually editing every file.

## Features

- Modify a Windows 11 ISO automatically
- Add custom files and folders
- Add `$OEM$` content
- Add setup scripts such as `SetupComplete.cmd` and first-logon scripts
- Integrate drivers
- Apply registry tweaks
- Add themes, wallpapers, icons, and other customizations
- Rebuild the modified installation media into a new ISO
- Designed to reduce repetitive manual ISO editing

## Requirements

- Windows 11
- Administrator privileges
- A legitimate Windows 11 ISO
- Enough free disk space for extracting and rebuilding the ISO

Some features may require additional tools depending on the configuration of the Maker.

## Usage

1. Download or clone this repository.
2. Obtain a legitimate Windows 11 ISO.
3. Run Win11-AlperEditionMaker as Administrator.
4. Select or provide your Windows 11 ISO.
5. Configure the desired modifications.
6. Let the Maker process the installation files.
7. The customized ISO will be generated locally on your computer.
